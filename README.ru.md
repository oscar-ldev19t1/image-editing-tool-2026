# image-editing-tool-2026

Лёгкая библиотека с открытым исходным кодом на Python для высокопроизводительной обработки изображений. Разработана как современный альтернативный вариант с приоритетом конфиденциальности вместо проприетарного программного обеспечения, она предлагает основные возможности редактирования без излишней сложности или затрат.

## Описание

`image-editing-tool-2026` предоставляет упрощённый API для общих задач обработки изображений. Независимо от того, автоматизируете ли вы рабочие процессы, создаёте веб-сервисы или просто нужно изменить размер и обрезать изображения локально, этот инструмент сохраняет ваши данные на вашем компьютере и минимизирует зависимости.

**Ключевая философия:**
*   **Локальный приоритет:** Данные не покидают ваш компьютер.
*   **Минимум зависимостей:** Построена на базе `Pillow` для максимальной совместимости.
*   **Удобство для разработчиков:** Пайтонический синтаксис с понятной документацией.

## Возможности

*   **Базовые операции:** Изменение размера, обрезка, поворот и отражение изображений.
*   **Корректировка цвета:** Яркость, контраст, насыщенность и преобразование в оттенки серого.
*   **Поддержка форматов:** Обрабатывает JPEG, PNG, GIF, WebP и TIFF.
*   **Пакетная обработка:** Эффективная обработка нескольких файлов в каталоге.
*   **Управление метаданными:** Чтение и удаление данных EXIF для конфиденциальности.
*   **Ленивая загрузка:** Эффективное управление памятью для больших файлов изображений.

## Установка

Убедитесь, что у вас установлен Python 3.8 или выше. Вы можете установить пакет через `pip`:

```bash
pip install image-editing-tool-2026
```

Или, если вы работаете с локальным клонированием:

```bash
git clone https://github.com/your-username/image-editing-tool-2026.git
cd image-editing-tool-2026
pip install -e .
```

## Пример использования

Ниже приведено краткое руководство по загрузке изображения, применению корректировок и сохранению результата.

```python
from image_editing_tool_2026 import Editor

# Инициализация редактора с исходным файлом
editor = Editor("input_photo.jpg")

# Применение серии операций
# 1. Изменение размера до ширины 1080p с сохранением пропорций
editor.resize(width=1080)

# 2. Корректировка яркости на 15%
editor.adjust_brightness(factor=1.15)

# 3. Преобразование в оттенки серого
editor.grayscale()

# 4. Сохранение результата
editor.save("output_edited.jpg", quality=90)

print("Image processed successfully.")
```

## Конфигурация

Вы можете настроить поведение инструмента с помощью переменных окружения или передав словарь конфигурации в класс `Editor`.

### Переменные окружения

| Переменная | Описание | По умолчанию |
| :--- | :--- | :--- |
| `IET_TEMP_DIR` | Каталог для временных файлов обработки. | Системный временный каталог |
| `IET_MAX_DIMENSION` | Максимальное измерение для автоматического изменения размера (пиксели). | `None` |
| `IET_VERBOSE` | Установите значение `1`, чтобы включить отладочное логирование. | `0` |

### Программная конфигурация

```python
from image_editing_tool_2026 import Editor

config = {
    "temp_dir": "/custom/path/to/temp",
    "verbose": True,
    "exif_strip": True  # Автоматически удалять метаданные при загрузке
}

editor = Editor("image.png", config=config)
```
